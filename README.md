# Pet Face Classification

A deep learning project that uses Convolutional Neural Networks (CNNs) to classify pet faces using TensorFlow and Keras.

## Overview
This project explores image classification techniques to identify pet faces through a trained deep learning model.

## Tech Stack
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Structure
```text
Pet-Face-Classification/
├── images/
├── pet_classification.ipynb
├── pet_classifier.keras
└── README.md
```

## How to Run
1. Clone the repository.
2. Install the required dependencies.
3. Open `pet_classification.ipynb` in Jupyter Notebook.
4. Run the notebook cells.

## Model
The trained model is saved as `pet_classifier.keras`.
